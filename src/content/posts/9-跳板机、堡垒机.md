# 1. 跳板机

运维人员 -> 跳板机 -> 目标服务器

跳板机处于内外网交界位置。运维人员使用自己的账号登录跳板机，跳板机连接目标服务器。目标服务器只允许跳板机这一个来源IP连接，其他连接请求全部拒绝。

## 1.1 常用跳板机

linux：ssh
windows：远程桌面 RDP(remote desktop protocol)

## 1.2 跳板机作用

1. 收口：千百台服务器只需要暴露一个入口。
2. 省事：连内网要用的脚本工具统一预装到跳板机上。跑长时任务可以放跳板机上挂着。
3. 记账：记录登录跳板机人员和时间。（只记登录不记操作）

## 1.3 跳板机缺点

1. 密码散
    1. 运维人员需要记录全部服务器的账号密码。
    2. 为了省事，全组共用一个root账号。
2. 权限一刀切，只要能登录跳板机，就能对服务器做任何操作。

# 2. 堡垒机

运维审计系统。在跳板机的基础上，加了一套管控和审计系统。

能够记录：谁 什么时间 什么身份 哪台机器 做了什么

## 2.1 堡垒机作用

1. 账号：保管服务器密码，运维不用知道服务器真实密码（可选）。登录服务器的密码可以定期轮换。
2. 认证：堡垒机对接公司统一的身份系统，每个员工用自己账号，离职就注销，失去所有权限。
3. 授权：谁 哪台机器 什么时间 操作内容
4. 审计：记录命令。会话回放。
